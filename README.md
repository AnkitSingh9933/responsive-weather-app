# 🌦 Weather App

A responsive weather application built using JavaScript and OpenWeather API.

---

# 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await

---

# 🚀 Features

- Search weather by city
- Live weather data
- Responsive design
- Dynamic UI updates
- Error handling
- Enter key support
- Mobile friendly layout
